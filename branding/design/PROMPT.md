# Задание для визуального макета

Встроенный image_gen, референс: client/images/bee-lazy-logo.jpg.

Создай один высококачественный визуальный макет UI мобильного VPN-приложения Bee Lazy: презентационный лист из ТРЁХ разных экранов рядом, каждый целиком, прямой вид без перспективы, без рук и предметов. Это концепт дизайна реального полного клиента Amnezia с собственным фирменным интерфейсом, а не рекламный сайт. Исходное изображение — только референс точного существующего логотипа пчелы и фирменного лаймового цвета; сохрани характер знака, не изобретай новую эмблему. Дизайн должен быть интересным, красивым, продуманным, визуально богатым деталями, но понятным для семьи любого возраста. Стиль: современный премиальный цифровой продукт, графитово-чёрный фон с мягкой фактурой, сливочно-белая типографика, лаймовый акцент из логотипа, чистая сетка, качественная крупная типографика, выразительные скруглённые поверхности, лёгкая глубина и тончайшие контуры. Без фиолетового, синих неоновых ореолов, киберпанка, игрушечных 3D-иллюстраций, избытка свечения, обещаний 100% защиты. Первый экран «Подключение»: сверху маленький знак и Bee Lazy, большая типографика «Ваше соединение под защитой», выразительная круговая кнопка подключения с многослойной тонкой геометрией и пчелой в центре; текст состояния «Подключено», ненавязчивый таймер; внизу карточка выбранного сервера «Семейный VPN», протокол «AmneziaWG», небольшие показатели скорости как ДЕМОНСТРАЦИОННЫЕ данные. Нижняя навигация на всех экранах: «Главная», «Серверы», «Настройки», текущий пункт выделен. Второй экран «Серверы»: понятный список собственных профилей, выбранный «Семейный VPN», второй «Личный профиль», кнопка «Добавить подключение», варианты импорта файлом и QR-кодом; не выдумывай реальные доступные страны, подписки и оплаченные серверы. Третий экран «Настройки»: аккуратные группы параметров «Подключение», «Автоподключение», «Раздельный туннель», «Оформление», «Помощь»; красивый переключатель, образцы тёмной и светлой темы; маленькая карточка о Bee Lazy с логотипом. Все подписи по-русски, корректные, короткие, без lorem ipsum. Между экранами единая система отступов, иконок и шрифтов. Фон презентационного листа нейтральный тёплый светлый, вокруг телефонов достаточно воздуха. Каждый экран должен выглядеть как тщательно спроектированный, пригодный к реализации интерфейс, а не обычный шаблон VPN. Внизу листа небольшая подпись «Bee Lazy · Концепция интерфейса». Не показывай реальные IP, ключи, пароли или персональные данные.
