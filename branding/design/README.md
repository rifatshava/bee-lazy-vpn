# Новый интерфейс Bee Lazy

Концепция от 11.11.2026 по требованию владельца: «И дизайн чтобы интересный был, красивый, непростой».

`concept-v1.png` — визуальный макет трёх экранов, созданный встроенным image_gen. Это изображение, а не снимок работающего приложения. В опубликованные установщики новый интерфейс ещё не включён.

Направление: графитовый фон, сливочная типографика, фирменный лайм, тонкие контуры, мягкая глубина, выразительная круглая кнопка подключения и единая нижняя навигация. Фирменная пчела — из существующего логотипа владельца.

Экраны: подключение, собственные серверы/профили, настройки. Основные действия остаются крупными и понятными для родных. Детальность дизайна не должна усложнять подключение.

При переносе в QML:

- Использовать реальные ConnectionController, ServersUiController и настройки; не заменять рабочее состояние статическими надписями.
- Состояния: отключён, подключается, подключён, ошибка, нет профиля. Фраза про защиту допустима только для подключённого состояния, без обещания абсолютной защиты.
- Не показывать демонстрационные таймеры, скорости и выдуманные серверы как настоящие данные. При отсутствии показателя скрывать его.
- Надпись «Ваши подключения Amnezia» в макете заменить на «Ваши подключения».
- Сохранить все рабочие способы импорта и настройки протоколов полного клиента.
- Цвета — через семантические токены AmneziaStyle; компоненты — отдельными QML-файлами по AGENTS.md. Для рабочих иконок использовать существующую систему проекта, не вырезать их из картинки.
- Анимация должна отражать состояние подключения, учитывать отключение анимации и не удерживать дорогие эффекты на невидимых экранах.
- Сначала реализовать и проверить главный экран на Android, затем список серверов/настройки и размеры настольных окон. Не нарушать VPN-логику.

Сборка, запуск и проверка нового дизайна ещё предстоят. Существующие APK/EXE/PKG остаются предыдущей базовой фирменной версией.
